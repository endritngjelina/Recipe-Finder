# Recipe Finder 🍽️

A simple, browser‑based tool for searching and exploring recipes. This project includes multiple HTML versions created during iterative development, UI testing, and feature experimentation.

## 🚀 Features
- Fully client‑side — no installation required  
- Fast recipe lookup and filtering  
- Multiple UI prototypes included  
- Clean, minimal interface  
- MIT‑licensed and easy to extend  

## 📁 File Overview
This repository contains several HTML versions created during development:

recipe finder 0.html
recipe finder 1.html
recipe finder 2.html
...
recipe finder 5.html

Each version explores different layouts, search logic, or interaction patterns.

## ▶️ How to Use
1. Download or clone the repository  
2. Open any `.html` file in your browser  
3. Search for ingredients or recipe names  
4. Explore results instantly  

## 🛠 Customization
Since the project uses plain HTML/CSS/JS, you can easily:
- Add new recipe datasets  
- Improve search logic  
- Add filters (time, difficulty, ingredients)  
- Redesign the UI or theme  
- Integrate API‑based recipe sources
